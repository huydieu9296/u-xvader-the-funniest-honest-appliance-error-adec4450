A single line — at most 200 characters — the funniest honest error message an
appliance could show. A washing machine, flatly, reports the fault every owner
already suspects:

> ERROR E07: I ate one sock. It was not an accident. Your wash is clean; the sock is gone. Please stop opening the door to check.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
No network, no dependencies, Node 22.
